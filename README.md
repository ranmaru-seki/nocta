# NOCTA — 夜のためのコーヒー定期便 LP

ポートフォリオ用の架空ブランド「NOCTA」の単品通販（D2C）LPデモサイトです。

- フレームワーク：Astro
- 公開：GitHub + Vercel（https://nocta-coffee.vercel.app）
- 画像：ACワークスの素材を切り抜き・WebP化して使用（元素材は `_raw/`、リポジトリには含めない）

## コマンド

| コマンド | 内容 |
| --- | --- |
| `npm install` | 依存パッケージのインストール |
| `npm run dev` | 開発サーバー（http://localhost:4321） |
| `npm run build` | `dist/` に本番用ビルド |
| `npm run preview` | ビルド結果の確認 |
